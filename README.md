# 群組裡的第六個人 — GitHub 上傳版

這個資料夾是一份可獨立運作的靜態網站。包含繁中／英文、手機直式聊天室、原創代號、自由文字回覆、借名惡搞與音效。不需要建置，不需要 API 密鑰。

## 異常紀錄更新

八輪自由聊天、三種主要結局，新增撤回警告、七人已讀與冒名通知。依本局已送出文字選擇門外敲擊、螢幕倒影、時間紀錄或無形在場的細節線；角色有不同打字節奏，重複訊息與假指令有專屬回應。結局圖片附上該路線的內建後記，不帶玩家原文。

撤回、已讀、私訊與明日通知都只是遊戲內演出，不使用系統通知、不讀未送出草稿或其他裝置。特效尊重減少動態設定；iOS、Android 與 Threads 內建瀏覽器的聲音、鍵盤及圖片分享仍需真機確認。

## 要上傳什麼

只上傳本資料夾內的全部內容，並保留 `assets` 資料夾結構。請讓 `index.html` 位在儲存庫網站的根目錄，不要把外面整個開發資料夾一起拖進去。

- `index.html`、`style.css`
- `script.js`、`story-engine.js`、`i18n.js`
- `public-names.js`、`name-guard.js`
- `soundscape.js`、`ending-card.js`
- `config.js`（後端網址與金鑰固定留空）
- `assets/icon.svg`、`assets/threads-cover.png`
- `.gitignore`、`README.md`、`PRIVACY.md`

直接開啟 `index.html` 可在電腦預覽。發布網站後再把公開網址分享給朋友；本機檔案網址不是可公開遊玩的網址。Threads 分享封面若無法顯示，請將 `index.html` 的 `og:image` 改成發布後封面圖片的公開 HTTPS 網址。

## 本版的隱私處理

- 沒有附帶開發備份、Git 歷史、測試資料、系統檔案、環境變數檔或憑證。
- 封面圖片的額外製作中繼資料已從這份副本移除，圖片像素不變；原圖另行保留在開發資料夾中。
- `config.js` 不包含後端網址或密鑰；匿名痕跡投稿功能因此不會啟用。
- 聊天內容只留在當前頁面，不上傳到 AI、資料庫或分析服務。
- 按鍵／送出聲、懸疑音樂與心跳均為本頁原創合成，不載入外部音樂。首頁可試聽、調音量與關閉音樂；頂端可隨時靜音或減少特效。
- 結局會自動產生 1080 × 1920 PNG，只含內建結局文案及虛構代號，不截取整個螢幕。可下載、長按儲存，或在瀏覽器支援時分享圖片；不含聊天、城市、裝置或群組名稱。
- 裝置大類仍由本頁推測。城市功能仍為玩家主動勾選後才連線到 IPWhois；該供應商會收到玩家當次的連線 IP。這與上傳作者的私人資料不同，詳見 [PRIVACY.md](PRIVACY.md)。
- 名人辨識使用有限的本機清單，不會上網查詢玩家輸入。第三個不同名字的隱去是故事效果，不是資料匿名化保證。

## 之後修改時請注意

這次檢查只適用於這份檔案的目前內容。之後不要加入真實聯絡方式、私人照片、聊天紀錄、私人網址或密鑰。所有放進公開網站的程式、設定與素材都可被訪客取得，不能靠改檔名或藏在 JavaScript 裡保密。

`.gitignore` 只是額外提醒與 Git 的排除規則，不能阻止你在網頁上手動上傳檔案。請勿上傳本資料夾以外的內容。若密鑰曾經公開，刪檔不等於撤銷，應到發行該密鑰的服務撤銷並重新產生。

GitHub 儲存庫及網站網址仍會顯示所使用的帳號或組織名稱；本資料夾無法隱藏你的 GitHub 公開身分。本次只準備檔案，沒有替你上傳或發布。
